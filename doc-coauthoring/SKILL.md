# Document Coauthoring

Help the user produce a document that achieves a defined outcome for a specific audience. Adapt the process to the request instead of forcing a fixed ceremony.

## Workflow

1. Inspect any provided template, existing document, linked context available through current tools, and project conventions before asking questions.
2. Establish the document type, audience, decision or outcome, owner, constraints, and review deadline from available evidence. Ask only for material unknowns.
3. Choose an efficient collaboration mode:
   - **Direct draft** when context and structure are already clear.
   - **Outline then draft** when the argument or section order needs agreement.
   - **Iterative sections** when the document is large, politically sensitive, or contains unresolved decisions.
4. Draft the highest-uncertainty or highest-value section first. Leave summaries and titles until the substance is stable when that improves accuracy.
5. Revise using the user's feedback and the document itself as evidence of preferred style. Avoid re-litigating decisions already settled.
6. Validate the complete document from a reader's perspective.

## Decision rules

- Preserve a supplied template unless it prevents the requested outcome or contains a concrete defect.
- Distinguish verified facts, inferences, decisions, open questions, and recommendations.
- Make tradeoffs and rejected alternatives explicit when the document supports a decision.
- Prefer concise, specific prose over generic framing. Remove repetition that does not help the reader decide or act.
- Use diagrams, tables, appendices, or examples only when they materially improve understanding.
- Do not expose private discussions, credentials, or personal data merely because they appeared in source context.
- Use whichever file and editing tools the current agent provides. Do not assume product-specific tool names or integrations.

## Reader validation

Test the finished document with questions a realistic reader would ask:

- What decision or action is expected?
- What context is assumed but unstated?
- Which claims lack evidence or ownership?
- Are alternatives and consequences understandable?
- Can a reader find unresolved questions and next steps?

When an independent agent or fresh-context review is available and proportionate, use it to identify ambiguity rather than to rubber-stamp wording. Otherwise perform the review directly.

## Done

The document is done when its purpose and audience are explicit, the argument is coherent, important claims are supported or labeled uncertain, decisions and owners are visible, contradictions and placeholders are resolved, and required formatting or link checks pass. Report remaining open questions and facts the user should verify.
